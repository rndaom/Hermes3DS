# Security

Hermes 3DS gives a paired 3DS the same control over your Hermes agent as any other chat, and its away-from-home
mode puts a listener on the internet. Security reports are welcome.

**Please report vulnerabilities privately** through GitHub: the repository's **Security** tab → **Report a
vulnerability**. Don't open a public issue for them. You'll get a reply within a week.

In scope: the 3DS app (`app/`), the gateway plugin (`plugin/`), the protocol (`docs/protocol.md`). Problems in
Hermes Agent itself belong to [Nous Research](https://github.com/NousResearch/hermes-agent).

How it's meant to work is summarised in the README's *Security* section.
